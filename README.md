# Last Minute

Bilingual Arabic/English company profile website for Last Minute, a flexible sourcing and supplier-brokerage company serving event organizers and businesses.

## Netlify deployment

The repository is deployment-ready. In Netlify, import this repository and use:

- Build command: leave empty
- Publish directory: `dist`

The same settings are already included in `netlify.toml`.

## Company profile

Downloadable PDF and PowerPoint versions are stored in `dist/downloads/`.

## Local preview

Serve the `dist` directory using any static web server.
